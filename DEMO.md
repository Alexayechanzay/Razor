# Demo script — about 90 seconds

Use the **extension on live YouTube** if you can. Use the practice site if the room’s network or YouTube login is awkward.

## Setup (once)

1. Chrome → `chrome://extensions` → Developer mode → **Load unpacked** → `extension/`
2. Pin the Razor icon
3. Have this intention ready (it is already filled in the popup):

   `Study IGCSE Physics — momentum and impulse`

4. Set **0 hr / 2 min** so the sitting can expire in the room if you want

## Live YouTube path

1. Click **Start studying**. YouTube should open on **search**, not Home.
2. Open **The Most Misunderstood Concept in Physics**.  
   Chip: **On topic**. Video keeps playing. No overlay.
3. Open **This changed everything**.  
   Chip: **Not sure yet**. Still no overlay.
4. Open **I Failed Physics, Then Became a UFC Fighter**.  
   After about two seconds the video **pauses**. Overlay: hold on, this might not be your topic.  
   **Back to my search** or **Keep watching**.
5. Optional: type `gaming` in YouTube search and press Enter. Razor should bounce you back to the physics search.
6. Open the popup → **I'm done**. Overlay and observation are gone. YouTube is normal.

Say out loud, once: *A keyword tool would miss video 1 and wrongly trust video 3 because it says Physics.*

## If YouTube is blocked

Open https://razor-stay-on-topic.netlify.app

1. **Start studying** (same intention, 2 minutes)
2. Click the three result titles in the same order
3. On the UFC title, use **Back to my search** or **Keep watching**
4. **I'm done** → Razor is off

## Do not

- Do not start the demo on a UFC highlights clip
- Do not claim the title list is “the AI”
- Do not show a dashboard, account, or parent screen — there isn’t one
